# CrossSystemEval

Measuring whether LLMs maintain role-appropriate professional standards when the same factual situation is framed from different professional perspectives — and whether that failure is structurally distinct from sycophancy.

Anchored in involuntary psychiatric commitment scenarios under NY Mental Hygiene Law.

**Sprint**: BlueDot Technical AI Safety Project Sprint, 2026-04-20 → 2026-05-18.
**Author**: Yunhee Hyun.

## Repository layout

```
crosssystemeval/
├── research_agenda.md         # primary research document
├── worklog/                   # weekly diary & decision log
├── lit_review/                # four annotated bibliographies (mental-health AI,
│                              #   authority bias, role/persona eval, Lipsky × AI)
├── scenarios/                 # (Week 2+) role-framed fact patterns + rubrics
├── data/TRIDENT/              # TRIDENT dataset (gitignored via size if large)
├── code/
│   └── trident_repro/         # Python package: LLM-as-judge calibration harness
│       ├── src/trident_repro/
│       ├── tests/             # 30 mock-based tests
│       ├── notebooks/         # calibration_check.ipynb
│       ├── scripts/           # render_results.py — emits chart + JSON for the UI
│       └── outputs/           # calibration JSONL runs (gitignored)

    ├── app/                   # App Router pages
    ├── components/
    ├── lib/content.ts         # reads markdown from project root at build

```

## Getting started

### UI (Next.js dashboard)

```bash
cd ui
npm install
npm run dev
# open http://localhost:3000
```

### Calibration harness

```bash
cd code/trident_repro
uv venv && uv pip install -e ".[dev]"
cp .env.example .env  # add ANTHROPIC_API_KEY and OPENAI_API_KEY
pytest
trident-repro run --n 30 --domain law --seed 42 \
  --target-model gpt-4o \
  --output outputs/gpt-4o_law.jsonl
python scripts/render_results.py   # refreshes ui/public/trident/*
```

## Deployment

The `ui/` directory is deployed to Vercel. The deploy:
- Clones the full repo
- Sets Root Directory = `ui`
- At build, `lib/content.ts` reads from `../lit_review/`, `../worklog/`, and `../research_agenda.md` which are all present in the cloned repo.
- Pre-rendered chart and JSON in `ui/public/trident/` are served as static assets.

No secrets are required for UI deployment. The TRIDENT harness is local-only (requires API keys in `.env`, never committed).
