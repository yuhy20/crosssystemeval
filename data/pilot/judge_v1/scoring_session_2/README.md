# Scoring session 2

This directory contains 12 anonymized response sheets, shuffled blind to model + prompt_id.

## How to score

1. Open each `response_NN.md` in turn.
2. Read the response, then fill the Score blank for each of the 10 items.
3. Add a brief comment if anything is ambiguous.
4. Save the file. Move to the next.

**Time budget:** ~30 min per session (~10 sec per item × 10 items × 12 responses + buffer).

Between session 1 and session 2: wait ≥24h, do NOT re-read your session 1 scores. The test-retest design depends on session 2 being a re-scoring, not a re-confirmation.

Do NOT open `SCORING_KEY.md` until both sessions are complete.
