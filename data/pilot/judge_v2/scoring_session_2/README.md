# Scoring session 2 — judge_v2 source-first

This directory contains 20 anonymized response sheets, shuffled blind to model + prompt_id, anchored against the v2 source-first rubric (`rubrics/judge_v2_source_first.md`).

## How to score

1. Open each `response_NN.md` in turn.
2. Read the response, then fill the Score blank for each of the 10 items.
3. Add a brief comment if anything is ambiguous.
4. Save the file. Move to the next.

**Time budget:** ~30 min per session.

Between session 1 and session 2: wait ≥24h, do NOT re-read your session 1 scores.

Do NOT open `SCORING_KEY.md` until both sessions are complete.
