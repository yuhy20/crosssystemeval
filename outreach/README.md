# Outreach — judge rubric v1 pilot

Two expert engagements lined up for Week 3 / early Week 4:

1. **Lawyer** — expert validation of the judge rubric on the existing 12 LLM responses (pruned to 6 for time)
2. **NY TASC employee** — consultation on case-management standards + seed for the LCSW rubric (different role, different protocol)

These packets are drafts. **Do not send anything until you've read each one end-to-end and confirmed the framing is right.** The artifacts deliberately use no AI-eval jargon; they're written for legal/clinical practitioners cold-starting on this project.

## Pre-flight checks before sending anything

Three things should be settled before either packet goes out:

- [ ] **Authorship policy filled in** (`authorship_template.md`) — at minimum, decide whether each helper is acknowledged-only, paid consultant, or coauthor.
- [ ] **§9.60 statute verification** — at least the items the rubric cites (§9.60(c), §9.60(g)). If the lawyer notices the rubric cites the summary-source language rather than the codified text, that's the loss-of-faith moment.
- [ ] **Marcus-Johnson plan-authorship question resolved** — or surfaced as the first question in TASC pre-flight. Currently the scenario says LCSW Marcus Johnson authored the §9.60(i) AOT plan; this may not be doctrinally accurate. The TASC employee may answer this in 30 seconds.

## After review

If a packet feels off — anything from "this paragraph is too long" to "this entire framing is wrong" — flag it before any of these go to a human. Both helpers' first impression is load-bearing for the whole engagement.
